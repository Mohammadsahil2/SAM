# SAM – Tune Your Mind

SAM is an AI-inspired productivity companion that helps users manage focus using brainwave frequencies, voice interaction, and visual feedback.

Features
• Brainwave frequency sessions
• Voice assistant
• Pomodoro focus timer
• Neural visual animations
• Progress analytics
• Installable web app

Tech Stack
HTML
CSS
JavaScript
Web Audio API
Chart.js
Canvas API

Created as a final-year BCA project.
